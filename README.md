# معرض الجود الشامي للحوم

تسلسل الطلب: بيانات التوصيل ← بيانات الطلب ← «يرجى الانتظار» ← موافقة الإدارة ← فورم رقم الهاتف ← تأكيد الاستلام.

## Firebase

تم تجهيز إعدادات مشروع gerty-b6913. اتبع [تعليمات Firebase](FIREBASE_SETUP.md) لتفعيل الدخول وصلاحية الأدمن ونشر القواعد والموقع. تم نشر المتجر على https://gerty-b6913.web.app ولوحة الأدمن على https://gerty-b6913.web.app/admin.html . بقي تفعيل Authentication وإعداد حساب الأدمن. التشغيل المحلي أدناه يبقى متاحاً.

## التشغيل

للتشغيل السريع من PowerShell داخل مجلد المشروع:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

يستخدم الملف نسخة Node.js الموجودة في .tools، أو النسخة المثبتة على الجهاز. يشغّل الخادم بالخلفية ويولّد كلمة مرور الإدارة أول مرة في .tools/admin-password.txt. افتح http://localhost:3000 للمتجر وhttp://localhost:3000/admin.html للأدمن؛ لا تستخدم Live Server لهذا المشروع.

للتشغيل اليدوي باستخدام Node.js المثبت على الجهاز:

```powershell
$env:ADMIN_PASSWORD = Read-Host 'اختر كلمة مرور الإدارة (12 حرفاً على الأقل)'
node server.cjs
```

- المتجر: http://localhost:3000
- لوحة الأدمن: http://localhost:3000/admin.html

سجّل الدخول بكلمة المرور التي اخترتها. تعرض لوحة الأدمن ثلاثة أقسام مستقلة: فورم بيانات التوصيل، فورم بيانات الطلب، وفورم الهاتف. يظهر كل فورم بمجرد إرسال خطوته، مع مرجع مشترك للزبون. تظهر الطلبات الجديدة تلقائياً. اضغط «موافقة» بجانب الطلب؛ خلال ثوانٍ يظهر فورم الهاتف للزبون. بعد تأكيده يظهر الرقم في لوحة الإدارة. يمكن تجربة الزبون والأدمن في متصفحين مختلفين.

يجب فتح المتجر عبر الخادم؛ فتح index.html مباشرة لا يشغّل إرسال الطلبات. لم يعد إرسال الطلب يفتح واتساب.

## الحفظ والاستضافة

تحفظ الطلبات في data/orders.json، ولا يتيح الخادم تنزيل ملف البيانات. جلسة الأدمن صالحة لثماني ساعات وتنتهي عند إعادة تشغيل الخادم. يحتفظ تبويب الزبون بمعرّف طلبه السري أثناء تحديث الصفحة.

لعمل الزبون والأدمن من أجهزة مختلفة، استضف الخادم على عنوان HTTPS مشترك مع قرص دائم لملف البيانات. اضبط HOST=0.0.0.0 وPORT حسب الاستضافة، وCOOKIE_SECURE=1 عند استخدام HTTPS. عند الاستضافة اضبط PUBLIC_ORIGIN على عنوان الموقع الكامل مثل https://shop.example.com بدون شرطة مائلة أخيرة، خصوصاً مع reverse proxy. الخادم لعملية واحدة؛ لا تشغّل عدة نسخ على ملف البيانات نفسه.

## التحقق

```powershell
node verify.cjs
node verify-server.cjs
```

اختبار الخادم يستخدم ملف بيانات مؤقتاً ويتحقق من منع إرسال الهاتف قبل الموافقة، وحماية الأدمن، والموافقة، والتحقق من الهاتف وحفظه.

المنتجات والأسعار في products.js، والتصميم في style.css. الصور وخيارات المنتجات من https://aljoudmeat.com.kw/، والأسعار لقطة بتاريخ 7 أكتوبر 2026، ويؤكد المعرض التوفر ورسوم التوصيل.
